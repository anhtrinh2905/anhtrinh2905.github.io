## ▶️ Run the Project (Local)

### 1) Clone repository
```bash
git clone https://github.com/anhtrinh2905/anhtrinh2905.github.io.git
cd anhtrinh2905.github.io
````

### 2) Install dependencies

Using npm:

```bash
npm install
```

> If you use `yarn` or `pnpm` instead:

```bash
# yarn
yarn

# pnpm
pnpm install
```

### 3) Start development server

```bash
npm run dev
```

Open in browser:

* [http://localhost:3000](http://localhost:3000)

### 4) Deploy using gh-pages

Deploy:

```bash
npm run deploy
```
